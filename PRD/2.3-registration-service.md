# PRD: Task 2.3 — Registration Service + API Endpoint

## Описание задачи

Создать сервис регистрации пользователя (`RegistrationService`) в Application слое и REST API эндпоинт `POST /api/register` для регистрации новых пользователей.

## Ограничения

- **Только Application + Infrastructure (Controller) слои** — никаких изменений в Domain
- **Использовать существующие VO** — `Email`, `PasswordHash`, `Role`, `UserId`
- **Использовать `UserRepositoryInterface`** — через DI, не конкретную реализацию
- **Пароль захешировать в сервисе** — через `PasswordHash::createFromPlain()`
- **Роль по умолчанию — `user`** (Role::user())
- **Email уникален** — проверка через `existsByEmail()` перед сохранением
- **Открываем только для гостей** — firewall `anonymous`, без авторизации
- **Валидация DTO** — Symfony Validator constraints
- **OpenAPI документация** — атрибуты `#[OA\Post]`, `#[OA\RequestBody]`, `#[OA\Response]`

## Структура ответов

### Success 201 Created
```json
{
  "id": "uuid-v7-string",
  "name": "John Doe",
  "email": "john@example.com",
  "role": "user",
  "is_active": true,
  "created_at": "2026-07-17T12:00:00+00:00"
}
```

### Error 400 Bad Request (валидация)
```json
{
  "type": "https://tools.ietf.org/html/rfc7807",
  "title": "Validation failed",
  "status": 400,
  "detail": "Invalid input data",
  "violations": [
    {"field": "email", "message": "This value is not a valid email address."},
    {"field": "password", "message": "Password must be at least 8 characters"}
  ]
}
```

### Error 409 Conflict (email существует)
```json
{
  "type": "https://tools.ietf.org/html/rfc7807",
  "title": "Conflict",
  "status": 409,
  "detail": "User with this email already exists"
}
```

## Domain Exception

Создать `src/Domain/User/Exception/UserAlreadyExistsException.php`:
```php
final class UserAlreadyExistsException extends \DomainException
{
    public static function withEmail(Email $email): self
    {
        return new self(\sprintf('User with email %s already exists', $email->value()));
    }
}
```

`RegistrationService` выбрасывает это исключение, Controller мапит в 409.
