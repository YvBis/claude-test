# PRD: Task 3.2 — Сущность CollectionField

## Описание задачи
Доменная сущность `CollectionField` с полями: `id`, `collection_id`, `name`, `type` (text/number/date/bool), `slot_index` (1..100), `created_at`, `updated_at`. `slot_index` уникален в пределах коллекции. Связь с `Collection` через ManyToOne c `ON DELETE CASCADE`. Только Domain + миграция + индекс; сервис/API — отдельные задачи.

## Ссылки на требования

- `artifacts/prd-taskflow-ru.md` — секция 5 ФР: динамические слоты айтемов через поля коллекции
- `artifacts/technical-requirements-taskflow-ru.md` — Doctrine ORM attributes, миграции через `doctrine/migrations`, `DATETIME(6)`, Symfony Clock, strict types

## Решения, принятые из артефактов
- **UUID `binary(16)` PK** — симметрия с `User`/`Collection` (см. 2.1, 3.1)
- **`name`** — отдельный VO `FieldName` (max 50, non-empty, trim), валидация на уровне домена
- **`type`** — backed enum `FieldTypeEnum` + VO `FieldType`. Допустимые значения: `text`, `number`, `date`, `bool`. `Choice` constraint VO Symfony выводится динамически через `FieldTypeEnum::cases()` — никакого хардкода
- **`slot_index`** — `SMALLINT`, диапазон 1..100, инвариант в конструкторе (бросает `InvalidArgumentException`). Константа `CollectionField::MAX_FIELDS_PER_COLLECTION = 100`
- **UniqueConstraint `(collection_id, slot_index)`** — на уровне БД, дубликаты slot невозможны
- **Lifecycle**: `HasLifecycleCallbacks` снят на entity. `createdAt` ставится в конструкторе, `updatedAt` через явный `touch()` из domain-мутаторов. `@ORM\PreUpdate` НЕ используется — Doctrine считает changeset до preUpdate, `touch()` там не персистится (внешнее ревью #4)
- **Repository interface** — `CollectionFieldRepositoryInterface` в Domain; реализация в Infrastructure (отдельный пункт — добавление имплементации идёт в 2.2-стиле User)
- **`fetch: 'LAZY'`** на `ManyToOne Collection` — избегаем N+1, загрузка по требованию

## Ограничения
- Только Domain + migration + repository interface. Никаких Application/Infrastructure сверх интерфейса
- Doctrine ORM attributes (PHP 8), таблица `collection_fields`
- Indexes/UniqueConstraints — class-level `#[ORM\Index]` / `#[ORM\UniqueConstraint]`, не в `#[ORM\Table(...)]` (внешнее ревью #3)
- VOs (`CollectionFieldId`, `FieldName`, `FieldType`) — readonly, strict types
- Enum `FieldTypeEnum` — PHP 8.1 backed `string`. Автозагрузка через `composer.json` PSR-4 (внешнее ревью #4)
- FK `collection_id` — `binary(16)`, `nullable: false`, `onDelete: CASCADE`
- `DATETIME(6)` precision — шесть знаков после запятой (Doctrine Migrations, не `schema:update`)
- Out of Domain: имплементация repository, application service — отдельные шаги
