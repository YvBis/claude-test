## Измерения по ходу

- **Срез 4a: совместимость доказана цитатами, не памятью.** DAMA 8.6.0:
  установленный манифест требует `phpunit/phpunit: ^11.5.41 || ^12.3.14`
  (H1 закрыта). Bridge 8.1.6: требует только `php >= 8.1`, в сьюте
  дормантен (ноль ссылок в `tests/`, нет регистрации в xml, env
  `disabled=1`) — бамп не нужен (H2 закрыта). Цель: phpunit **12.5.37**.
- **Срез 4a: null-гард доказан двусторонне.** Файл без `<metrics>` →
  `coverage-gate: no project metrics in … (expected …)` + exit 1;
  настоящий clover → `passed`, exit 0. Проба транзиентная, clover
  восстановлен из бэкапа.

- **Срез 4b: список падений — 57 PHPUnit Notices, 0 failures.**
  `createMock` без `->expects()` (новинка 12-й: «No expectations were
  configured… use a test stub»). Exit code при этом 0 — гейты не краснеют,
  но 57 `N`-маркеров отравляют доверие к зелёному прогону. XSD-схема 12:
  `phpunit.xml.dist` валиден как есть, миграция не нужна.
  `failOnDeprecation="true"` и `--display-deprecations` на месте
  (пины `DeprecationConfigTest` держат).
- **Срез 4c: 8 классовых атрибутов вместо 57 правок.** Разбор: blanket
  `createMock`→`createStub` невозможен — `->expects()` пишется чейнингом
  с новой строки (мой первый греп `->expects\(` его не видел; второй заход
  сломал 11 тестов, откачено), а свойства типизированы `X&MockObject`.
  Решение: `#[AllowMockObjectsWithoutExpectations]` на класс (валиден:
  `TARGET_CLASS|TARGET_METHOD`) — действует только на моки без ожиданий,
  моки с `expects()` верифицируются как раньше. Итог: `OK (766/2684)`,
  ноль notices. Урок в память: однострочный греп врёт на чейнинг —
  проверять многострочные паттерны.
