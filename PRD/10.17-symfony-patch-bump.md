# 10.17 — Патч-бамп Symfony 7.4.20 → 7.4.23 (18 advisories)

## Почему

`main` покраснел на job'е `Dependency Audit` после мержа docs-only PR #189: это не регрессия от документации, а публикация новой волны Symfony security advisories 2026-11-05/06. Гейт `composer audit` блокирующий, поэтому прод-готовность требует бампа.

Замер до правки (`composer audit --format=json` в контейнере): **18 advisories в 11 пакетах**, все закрыты в `>=7.4.23`:

| Пакет | Шт. | Что закрыто |
|---|---|---|
| `symfony/http-foundation` | 4 | **CVE-2026-118514** (HEAD обходит `methods` в `access_control`), path-rules bypass через дописанный путь, `private_ranges` доверяет IPv4-mapped IPv6, host из клиента в сгенерированных URL |
| `symfony/serializer` | 3 | CVE-2026-118515 (UploadedFile из данных запроса), DataUri с не-нижним регистром, dotted-key traversal через `#[Ignore]` |
| `symfony/http-client` | 2 | утечка креденшелов default-scope на другие origin, непнинг checked IP в `NoPrivateNetworkHttpClient` |
| `symfony/security-http` | 2 | CVE-2026-118513 (X509 + escaped RDN), programmatic login обходит `checkPostAuth()` |
| `symfony/config`, `filesystem`, `framework-bundle`, `http-kernel`, `routing`, `validator`, `yaml` | по 1 | XXE в XmlUtils, escape пути в Filesystem, `private_ranges`-shortcut, forwarded headers в inline-фрагментах, CVE-2026-118516 (host placeholder матчит начало пути), Ip constraint, квадратичный YAML-парсер |

**Почему это важно именно здесь:** `CVE-2026-118514` — про `methods` в `security.yaml`, а правила проекта (`^/api/collections`, `^/api/items`, `^/api/search`) перечисляют `methods` явно (`GET`, `HEAD`). То есть до бампа `HEAD` мог обходить method-фильтр на публичных чтениях, а после — фильтр работает штатно. Наши тесты (`RouteAccessGuardTest`, `SecurityGuestReadTest`, HEAD-кейсы fwd-7) проверяют это поведение явно.

## Что сделано

```
composer update "symfony/*" --with-dependencies
```

- `composer.json` не тронут (констрейнты `^7.4` уже допускали патч), изменился только `composer.lock`: 344 вставки / 342 удаления;
- `symfony/framework-bundle` и `symfony/http-foundation`: `v7.4.20` → `v7.4.23`;
- `composer audit` после бампа: **No security vulnerability advisories found**.
