# PRD: Task 1.2 — Symfony Clean Architecture Scaffold

## Scope
Создать Symfony 7 проект с Clean Architecture структурой каталогов. Только каркас — никакой бизнес-логики, сущностей, тестов, качества кода, OpenAPI.

## Constraints
- **PHP 8.3**, **Symfony 7 LTS** (текущая версия на момент создания)
- **Doctrine ORM** + миграции (конфигурация + работающий коннект к БД для `doctrine:migrations:status`)
- **Symfony Messenger** + Redis transport (конфигурация)
- **Composer dependencies** — минимальный набор для инфраструктуры
- **Папки**: `src/Domain`, `src/Application`, `src/Infrastructure`
- **No** PHPUnit, PHPStan, PHPcsFixer, Rector, PHPCPD, Infection, OpenAPI — это задачи 1.3, 1.4, 1.6
- **No** User/Collection/Item entities — это Этап 2+
- **No** auth настройка — это задача 2.4

## Acceptance Criteria
- `composer install` проходит без ошибок
- `php bin/console --version` показывает Symfony 7.x
- `php bin/console doctrine:migrations:status` работает (подключается к MySQL в docker-compose)
- Папки `src/Domain`, `src/Application`, `src/Infrastructure` существуют и замаплены в `services.yaml`
- Нет ни одного теста, сущности, контроллера, OpenAPI конфига

## Out of Scope (explicit)
- PHPUnit / phpunit.xml.dist — задача 1.4
- PHPStan / PHPcsFixer / Rector / PHPCPD — задача 1.3
- OpenAPI / Swagger / NelmioApiDocBundle — задача 1.6
- User entity / roles / auth — задача 2.1, 2.4
- Collection / Item entities — задачи 3.1, 4.1
- Meilisearch интеграция — задача 6.1
- CI pipeline — задача 1.5
