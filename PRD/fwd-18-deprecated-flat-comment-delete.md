# PRD: fwd-18 — канонический вложенный DELETE комментария

Задача из Review Backlog (`Roadmap.md`, строка `fwd-18`). Решение пользователя
2026-09-27: вложенный путь канонический. Реализация — 2026-09-27, волна 1 очереди,
в одном PR с `fwd-11` (решение пользователя: вклинить). **Закрывает мини-этап 5A.**

## Зачем

Два DELETE-пути на один ресурс (`CommentController::delete` и `::deleteInItem`) —
задвоение поверхности без канонического адреса. Senior-review fwd-27: поведение при
совпадении `itemId` обязано быть идентичным (`delete` — 404, как и вложенный).

## Объём

- `DELETE /api/items/{itemId}/comments/{id}` — канонический: полный `description`,
  пример, `summary` без отсылки к плоскому.
- `DELETE /api/comments/{id}` — рабочий, но `deprecated: true` в аннотации + строка
  «используйте вложенный путь». Проверка синьором: `deprecated` — валидное поле
  `OperationTrait` в swagger-php 5.8.3, nelmio эмитит как есть; подтвердить по
  регенерированному JSON (`"deprecated":true` на плоском пути).
- Runtime-заголовок `Deprecation`/`Sunset` **не** добавляется: контракт ответа
  заморожен мини-этапом 5A, дата sunsets — продуктовое решение (кандидат в бэклог).
- Roadmap: `fwd-18 → done` + строка гейта этапа 6 — момент, когда условие «закрыт
  мини-этап 5A» впервые выполнено (остаются 5.14/5.20/5.25/5.26).

## Вне объёма

- Удаление плоского пути (breaking change, только через sunset-решение).
- `Sunset`-заголовок и дата удаления.
- Изменение порядка проверок 401→404→404→403 (правильный, фиксируется тестами).
