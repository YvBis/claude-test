# PRD — 7.1: список пользователей для админа

**Статус:** done (смержен в PR #149)

**Оценка:** ~1.5ч (7.1a ~0.5ч, 7.1b ~1ч)

**User story:** artifacts/prd-taskflow-ru.md:58 — «как администратор, я хочу
получать список пользователей со всеми их данными».

## Решения (зафиксированы до кода)

- **Маршрут:** `GET /api/admin/users` (неймспейс под 7.2–7.4, 7.6; PRD:57
  про обычный юзерский список не блокируется).
- **Гард:** `#[IsGranted('ROLE_ADMIN')]` на action — override владельца
  против рекомендации синьора (строка `access_control`). Цена: каждый
  будущий admin-action обязан нести атрибут. Механическая страховка —
  гардрил-тест в 7.1b (все роуты `/api/admin*` → 403 для ROLE_USER).
- **Поля:** колонки сущности минус хеш, без агрегатов. Осознанное
  отклонение от буквы «все поля» (хеш не отдаём никогда).
- **UserDTO в рантайме и в логине** (решение владельца): `LoginController`
  переводится на `UserDTO`, ответ байт-в-байт тот же.

## Скоуп

### 7.1a — порт + DTO + юнит (~0.5ч)

- `UserRepositoryInterface::findAll(int $limit = 50, int $offset = 0)`:
  дефолты сохраняют единственный caller (`testFindAll`).
- Doctrine: `ORDER BY created_at DESC, id DESC` (тайбрейк по первичному
  направлению, fwd-27) + контракт стабильности в докблок порта.
- Граничный тест: две строки с равным `createdAt` стоят по страницам.
- Миграция `testFindAll` на limit/offset.
- `UserDTO` (7 ключей, `ArrayableInterface` + провайдер fwd-3).

### 7.1b — контроллер + гард + функц. + OpenAPI (~1ч)

- `Admin/UserController.php` (`Controller/Admin/`, имя `api_admin_*`):
  `parsePagination` (400), не-скаляры 400 (fwd-25).
- Гардрил-тест: все роуты `/api/admin*` → 403 для ROLE_USER.
- Функциональные: админ видит 7 ключей, хеш отсутствует
  (`assertArrayNotHasKey`), юзер → 403, гость → 401, пагинация.
- `LoginController` → `UserDTO` (ответ тот же); blast: LoginControllerTest.
- OpenAPI: схема `User`, regen + `openapi:fresh` + frozen-списки.

## Карта ошибок (5.9)

Нет токена → 401, не-админ → 403, битые параметры → 400. 404/422 на этом
маршруте не возникают (нет id в пути, нет тела).

## Вне скоупа

- Агрегаты (счётчики коллекций/айтемов, last login) — не существуют.
- PRD:57 (обычный юзерский список) — отдельная будущая задача.
- 7.2–7.4 — переиспользуют гард и неймспейс, не перерешают.
