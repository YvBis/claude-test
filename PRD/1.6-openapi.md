# PRD: Task 1.6 — Документация OpenAPI (Swagger)

## Описание задачи
Настроить генерацию и рендеринг OpenAPI 3.x спецификации для всех API эндпоинтов. Подготовить к интеграции в CI (проверка валидности спецификации). На этом этапе бизнес-логики нет — только каркас, но инфраструктура должна быть готова.

**API docs только в dev окружении** — бандл в `require-dev`, конфиг в `config/packages/dev/`.

## Ссылки на требования
- `artifacts/technical-requirements-taskflow-ru.md` — секция 1 «Технологический стек» (пункт 7), секция 7 «Требования к CI/CD»
- `artifacts/prd-taskflow-ru.md` — нефункциональное требование: «Все роуты должны быть задокументированы в опен Апи»
- Стек: PHP 8.3, Symfony 7.4, только инфраструктурный код

- **Реальные бизнес-контроллеры** (User, Collection, Item, etc.) — этапы 2–7
- **JWT / Security схемы** — Task 2.4 (securitySchemes placeholder в конфиге допустим)
- **CI интеграция `openapi:validate`** — Task 1.5 (если CI уже есть, добавить job; иначе деферрировать)
- **Кастомные нормализаторы / групп сериализации** — по мере появления DTO
- **Примеры ответов из реальных сущностей** — нет сущностей
- **Описание ошибок (Problem Details / RFC 7807)** — позже, при единообразной обработке ошибок
- **Prod маршруты для документации** — dokc только в dev
