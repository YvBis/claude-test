# PRD 5.5 — API-эндпоинты лайков и комментариев

Этап 5 (Социальное). API-слой над сервисами 5.3 (`LikeService`) и 5.4 (`CommentService`).

## Цель

Дать REST-интерфейс к социальным функциям айтемов: лайки, комментарии и чтение чужих айтемов (без чего социальная функция не работает).

## Требования PRD

- 19: «ставить и смотреть лайки и комментарии у айтемов»
- 20: «менять свои лайки и комментарии у айтемов»
- 55/56: пользователь хочет лайкать и комментировать под своим именем, «чтобы все видели моё мнение»
- 84: «удаление и редактирование лайков и комментариев других пользователей администратором»
- 103: получить все комментарии айтема
- 104: оставить комментарий к айтему
- 105: поменять свой комментарий к айтему
- 106: поставить лайк айтему
- 107: получить все лайки айтема
- 117: администратор может поменять или удалить комментарий любого пользователя
- 118: администратор может удалить лайк любого пользователя

## Эндпоинты

| Метод | Путь | Успех | Доступ |
|---|---|---|---|
| POST | `/api/items/{id}/likes` | 200 `{likes_count}` | любой аутентифицированный |
| DELETE | `/api/items/{id}/likes` | 204 | любой аутентифицированный |
| GET | `/api/items/{id}/likes` | `LikeDTO[]` | любой аутентифицированный |
| DELETE | `/api/likes/{id}` | 204 | автор лайка или админ (PRD 118) |
| POST | `/api/items/{id}/comments` | 201 `CommentDTO` | любой аутентифицированный |
| GET | `/api/items/{id}/comments` | `CommentDTO[]` | любой аутентифицированный |
| PATCH | `/api/comments/{id}` | 200 `CommentDTO` | автор или админ (PRD 117) |
| DELETE | `/api/comments/{id}` | 204 | автор или админ |
| GET | `/api/comments` | `CommentDTO[]` | свои (scope-add, PRD 20) |

Все маршруты попадают под `^/api` auth-catch-all — изменения `security.yaml` не требуются.

Все списочные эндпоинты принимают `?limit` (по умолчанию 50, диапазон 1..100) и `?offset` (по умолчанию 0).

Детальный эндпоинт `GET /api/items/{id}` отдаёт `ItemDetailDTO`: базовые поля айтема плюс `likes_count`, `comments_count`, `liked_by_me` (счётчики только здесь — см. «Счётчики»).

## Карта ошибок

| Ситуация | Статус |
|---|---|
| Битый или несуществующий id (item/like/comment) | 404 |
| Невалидный контент комментария (пусто / >3000) | 422 |
| Отсутствующий `content` в теле или нестроковый `content` | 422 (ключ отсутствует → дефолт `''` → домен) |
| Битый JSON | 400 (`NotEncodableValueException` / `NotNormalizableValueException`) |
| Лайк/комментарий несуществующего айтема | 404 (через `ItemService::getById`) |
| Unlike несуществующего лайка | 204 (идемпотентно; асимметрия с «айтем не найден → 404» задокументирована) |

Счётчики читаются **после** мутации (`like()`/`create()` делают flush внутри).

## Чтение чужих айтемов (D1 Этапа 5)

Социальная функция требует, чтобы аутентифицированный пользователь видел чужие айтемы.
`ItemController::get`, `ItemController::listByCollection` и `CollectionController::get` переводятся с «владелец+админ» на «любой аутентифицированный».
`GET /api/items` (список своих айтемов) остаётся owner-scoped.
Гостевой (анонимный) доступ остаётся отложенным — `fwd-7`.

## Счётчики

`GET /api/items/{id}` получает `likes_count`, `comments_count`, `liked_by_me` через `ItemDetailDTO` (`allOf: [Item]` в OpenAPI).
В списках счётчики не отдаются (иначе N+1 на каждый айтем страницы) — batch-агрегация отложена в `fwd-8`.

## Решения (по ревью архитектора 2026-09-17)

- `LikeDTO.owner_name` добавляется (лайкер отображается по имени; `DoctrineLikeRepository` уже JOIN FETCH-ит `l.owner`).
- Счётчики — вариант C (`ItemDetailDTO`), только detail-эндпоинт.
- 5.5 владеет author+admin модерацией; Roadmap 7.6 пере-скоупится на админ-аудит/списки/UI.
- `GET /api/comments` (мои комментарии) — scope-add (PRD 20), иначе `listByOwner`/`countByOwner` из 5.4 мертвы.
- POST-ответ лайка — `{likes_count}` (без избыточного `liked`, который всегда `true`).
- `DELETE /api/likes/{id}` — путь админского удаления (PRD 118), использует `LikeService::getById`/`removeLike`.
- `CommentRequestDTO` — тонкий DTO без `#[Assert]` на контенте (валидация в доменном `CommentContent` → 422, иначе `Assert` дал бы 400), с дефолтом `public string $content = '';`.
