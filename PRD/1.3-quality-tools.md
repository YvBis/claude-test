# PRD: Task 1.3 — Инструменты качества кода

## Описание задачи

Настроить обязательные инструменты качества кода: PHPStan (статический анализ), PHPcsFixer (форматирование), Rector (авто-рефакторинг), PHPCPD (детекция копипасты). Добавить конфигурацию в проект и подготовить к интеграции в CI (Task 1.5).

## Ссылки на требования

- `artifacts/technical-requirements-taskflow-ru.md` — секция 4 «Обязательные инструменты качества», секция 5 «Требования к тестированию», секция 7 «Требования к CI/CD»
- Стек: PHP 8.3, Symfony 7.4, PHPUnit, PHPStan, PHPcsFixer, Rector, PHPCPD, composer audit

## Подзадачи (≤2ч / ≤150 строк каждая)

### 1.3.1 PHPStan — статический анализ

- Установить `phpstan/phpstan`, `phpstan/phpstan-symfony`, `phpstan/phpstan-doctrine`, `phpstan/phpstan-deprecation-rules`
- Создать `phpstan.neon` с уровнями: базовый уровень 6 для `src/`, уровень 5 для `tests/`
- Настроить extensions: symfony, doctrine, deprecation-rules
- Исключить сгенерированный код (migrations, kernel cache, var/)
- Добавить скрипт в `composer.json`: `phpstan analyse src tests --memory-limit=512M`
- Проверить: `composer phpstan` завершается без ошибок на чистом скелете

### 1.3.2 PHPcsFixer — форматирование кода

- Установить `friendsofphp/php-cs-fixer`
- Создать `.php-cs-fixer.dist.php` с правилами:
  - `@Symfony`, `@PSR12`, `@PHP83Migration`
  - Строгие типы: `strict_param`, `return_type_declaration`
  - Упорядок импортов: `ordered_imports`, `no_unused_imports`
  - Исключить: `var/`, `vendor/`, `migrations/`, `public/`
- Добавить скрипты в `composer.json`:
  - `phpcs:fix` — исправление
  - `phpcs:check` — проверка (dry-run)
- Проверить: `composer phpcs:check` проходит на чистом коде

### 1.3.3 Rector — автоматические рефакторинги

- Установить `rector/rector`, `rector/rector-symfony`
- Создать `rector.php` с наборами правил:
  - `SetList::PHP_83` (миграция на PHP 8.3 синтаксис)
  - `SetList::SYMFONY_70` (миграция на Symfony 7.x)
  - `SetList::DEAD_CODE` (удаление мёртвого кода)
  - `SetList::CODE_QUALITY` (улучшения качества)
- Исключить: `var/`, `vendor/`, `migrations/`, `tests/` (тесты не трогать)
- Добавить скрипты в `composer.json`:
  - `rector:dry-run` — проверка без изменений
  - `rector:fix` — применение
- Проверить: `composer rector:dry-run` проходит без ошибок

### 1.3.4 PHPCPD — детекция копипасты

- Установить `sebastian/phpcpd`
- Добавить скрипт в `composer.json`: `phpcpd src tests` с исключением `var/`, `vendor/`, `migrations/`
- Порог: 0% копипасты (любое совпадение > 5 строк = ошибка)
- Проверить: `composer phpcpd` возвращает 0 на чистом коде

### 1.3.5 composer.json — обновление scripts секции

- Объединить все скрипты в `scripts` с понятными именами
- Добавить агрегатный скрипт `ci:static` для запуска всех проверок разом
- Добавить `ci:lint` синоним для `phpcs:check`

### 1.3.6 Проверка сборки и baseline

- Запустить `composer install` — все пакеты устанавливаются без конфликтов
- Запустить `composer ci:static` — все 4 инструмента проходят (PHPStan 5-6, phpcs:check, rector:dry-run, phpcpd)
- Создать `phpstan-baseline.neon` если PHPStan выдаёт ошибки на сгенерированном коде (кэш, прокси) — закоммитить baseline
