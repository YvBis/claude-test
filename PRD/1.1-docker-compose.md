# PRD: Task 1.1 — Docker Compose Infrastructure

## Описание задачи
Настроить Docker Compose окружение с сервисами: приложение (PHP-FPM), веб-сервер (nginx), БД (MySQL 8), Redis, Meilisearch.

## Подзадачи (≤2ч / ≤150 строк каждая)

### 1.1.1 Dockerfile для PHP 8.3-fpm
- Базовый образ: php:8.3-fpm
- Установка расширений: pdo_mysql, mbstring, exif, pcntl, bcmath, gd, zip
- Установка Composer
- Настройка пользователя www-data (UID/GID 1000)
- custom.ini с настройками PHP
- EXPOSE 9000, CMD ["php-fpm"]

### 1.1.2 docker-compose.yml
- 5 сервисов: app, nginx, db, redis, meilisearch
- app: build из Dockerfile, volumes для кода + vendor/var кэши
- nginx: alpine, порт 8000→80, конфиг из docker/nginx/default.conf
- db: mysql:8.0, healthcheck mysqladmin ping, volume mysql_data
- redis: alpine, порт 6379, volume redis_data
- meilisearch: getmeili/meilisearch:v1.6, мастер-ключ, порт 7700, volume meilisearch_data
- depends_on с conditions (healthy/started)
- env vars: DATABASE_URL, REDIS_URL, MEILISEARCH_URL, MEILISEARCH_MASTER_KEY

### 1.1.3 nginx конфиг
- root /var/www/html/public
- try_files $uri /index.php$is_args$query_string (исправить дубль $is_args)
- fastcgi_pass app:9000 для *.php
- блок PHP доступен только через index.php
- access/error логи

### 1.1.4 Проверка работоспособности
- docker compose up -d
- Все 5 контейнеров healthy/up
- DB ping OK, Redis PONG, Meilisearch /health = available
- nginx отвечает на :8000 (404 ожидаемо — нет Symfony приложения)

## Критерии приёмки
- [x] 1.1.1 Dockerfile создан и собирается
- [x] 1.1.2 docker-compose.yml поднимает все сервисы
- [x] 1.1.3 nginx конфиг без ошибок синтаксиса
- [x] 1.1.4 Все healthchecks проходят, сервисы доступны
