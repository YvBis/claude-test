# PRD: Task 1.4 — PHPUnit с отчётами покрытия кода

| Пакет | Версия | Примечание |

**Запрещено:** использовать `dev-*`, `*`, версии без фиксации minor. Все версии через `composer require --dev vendor/pkg:^X.Y`.

**Выбрано:** Xdebug для покрытия кода.

**Примечание:** PHPUnit ^11.0 конфликтует с `sebastian/phpcpd^6.0` (требует `sebastian/version^3.0`), поэтому используется ^9.0 — это LTS версия, совместимая со стеком качества (PHPStan, Rector, php-cs-fixer, php-cpd).
