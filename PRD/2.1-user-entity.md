# PRD: Task 2.1 — User Entity с role и is_active

## Описание задачи
Создать доменную сущность `User` с полями: `id`, `name`, `email`, `password_hash`, `created_at`, `updated_at`, `is_active`, `role` (user/admin). Сущность должна находиться в `src/Domain/User/`.

**Важно**: `guest` — это неаутентифицированный запрос (нет User в БД). Symfony Security обрабатывает через `IS_AUTHENTICATED_ANONYMOUSLY` / firewall `anonymous`. В сущность User попадают только зарегистрированные пользователи → роли: `user`, `admin`.

## Ограничения
- **Только Domain слой** — никаких репозиториев, сервисов, контроллеров, API, миграций
- **Doctrine ORM attributes** для маппинга (PHP 8 attributes)
- **Value Objects** для Email, Role, PasswordHash — инкапсуляция валидации
- **Нет аутентификации/авторизации** — это Task 2.4
- **Нет миграций** — создаются в Task 2.2 вместе с Repository
- **Soft delete не нужен** — is_active boolean достаточно (domain-model: "Агент может принять решение по soft delete")
