# PRD: Task 1.5 — CI Pipeline (GitHub Actions)

## Описание задачи
Настроить CI-пайплайн в GitHub Actions, который запускает все инструменты качества кода и тесты на каждом push/PR. Пайплайн должен блокировать merge при неудаче любой проверки.

## Ссылки на требования
- `artifacts/technical-requirements-taskflow-ru.md` — секция 7 «Требования к CI/CD»
- Стек: PHP 8.3, Symfony 7.4, MySQL, Redis, Meilisearch
- Инструменты качества: PHPStan, PHPcsFixer, Rector, PHPCPD, PHPUnit, composer audit

## Подзадачи (≤2ч / ≤150 строк каждая)

### 1.5.1 Базовый workflow файл
- Создать `.github/workflows/ci.yml`
- Триггеры: `push` (branches: [main]), `pull_request` (branches: [main])
- `permissions: contents: read`
- `concurrency: group: ci-${{ github.ref }}, cancel-in-progress: true`

### 1.5.2 Job: static-analysis (линтеры, статика, копипаста)
- `runs-on: ubuntu-latest`
- Services: `mysql:8.0` (healthcheck), `redis:alpine`
- Steps:
  - Checkout
  - Setup PHP 8.3 avec extensions: pdo_mysql, mbstring, exif, pcntl, bcmath, gd, zip, redis, xdebug (mode=coverage)
  - Cache composer (`~/.composer/cache`, key: `composer-${{ hashFiles('composer.lock') }}`)
  - `composer install --no-progress --no-interaction`
  - `composer ci:static:quality` (запускает PHPStan, PHPcsFixer check, Rector dry-run, PHPCPD)
- Timeout: 15 min

### 1.5.3 Job: unit-tests
- `runs-on: ubuntu-latest`
- Services: `mysql:8.0` (healthcheck), `redis:alpine`
- Steps:
  - Checkout
  - Setup PHP 8.3 + extensions (под те же, + xdebug для coverage)
  - Cache composer
  - `composer install --no-progress --no-interaction`
  - `php bin/console doctrine:database:create --if-not-exists --env=test`
  - `php bin/console doctrine:migrations:migrate --no-interaction --env=test`
  - `composer phpunit` (с coverage)
  - Upload coverage artifact (`var/coverage/`)
- Timeout: 15 min

### 1.5.4 Job: dependency-audit
- `runs-on: ubuntu-latest`
- Steps:
  - Checkout
  - Setup PHP 8.3
  - Cache composer
  - `composer install --no-progress --no-interaction`
  - `composer audit --locked`
- Timeout: 5 min

### 1.5.5 Job: ci-summary (опционально, зависит от всех выше)
- `needs: [static-analysis, unit-tests, dependency-audit]`
- `if: always()`
- Агрегирует статус, публикует summary в PR/Action run

### 1.5.6 Настройка .env.test
- Создать/обновить `.env.test` с:
  - `APP_ENV=test`
  - `APP_SECRET=test-secret-key-ci`
  - `DATABASE_URL=mysql://test:test@127.0.0.1:3306/taskflow_test?serverVersion=8.0`
  - `MESSENGER_TRANSPORT_DSN=redis://127.0.0.1:6379`
  - `MEILISEARCH_URL=http://127.0.0.1:7700`
  - `MEILISEARCH_KEY=masterKey123`

### 1.5.7 Проверка пайплайна
- Запустить workflow вручную или пуш в ветку
- Все 3 основных job должны проходить зелёными
- При ошибке в любом job — merge заблокирован
