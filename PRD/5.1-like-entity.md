# PRD 5.1 — Сущность Like

## Статус

План. Подзадача Этапа 5 (Социальное). Декомпозиция утверждена пользователем (D1–D6, 2026-09-15).

## Описание

Сущность `Like` — отметка «нравится» на айтеме. Один лайк на (пользователь, айтем) — UNIQUE. Удаление — через каскад (айтем/пользователь удалены → лайк удалён). Таймстамп создания.

## Требования (артефакты)

- `Like`: `id`, `owner_id`, `item_id` (domain-model).
- Уникальность: «Один лайк принадлежит одному пользователю для одного айтема».
- PRD: «поставить лайк айтему», «получить все лайки айтема», «админ может удалить лайк любого пользователя».

## Решения (утверждены)

- D2: `Like.owner` = `ManyToOne User`, `Like.item` = `ManyToOne Item` (консистентно с Collection/Item; final-сущности → JOIN FETCH в read-методах).
- D1: доступ — на уровне API (5.5); сущность/домен без правил доступа.

## Декомпозиция

Одна подзадача (≤150 строк):

- `LikeId` VO (`src/Domain/Like/ValueObject/LikeId.php`) — бинарный UUID, паттерн `ItemId`/`TagId`.
- `Like` entity (`src/Domain/Like/Entity/Like.php`) — id, owner (`ManyToOne User`, ON DELETE CASCADE), item (`ManyToOne Item`, ON DELETE CASCADE), createdAt; `create(User, Item)` фабрика, `ClockAwareTrait`; UNIQUE `(owner_id, item_id)`.
- `LikeRepositoryInterface` (`src/Domain/Like/Repository/LikeRepositoryInterface.php`) — `save`, `remove`, `findByOwnerAndItem(OwnerId|UserId, ItemId)`, `findByItemId(ItemId, limit, offset)`, `countByItemId(ItemId)`.
- `DoctrineLikeRepository` — JOIN FETCH-цепочки (owner, item→collection→owner) против ghost-proxy; `IDENTITY`-сравнения бинарных UUID.
- Миграция: таблица `likes` (`id` binary PK, `owner_id` binary FK→users CASCADE, `item_id` binary FK→items CASCADE, `created_at` DATETIME(6), INDEX `idx_like_item` (item_id), UNIQUE `uniq_like_owner_item` (owner_id, item_id), `COLLATE utf8mb4_0900_ai_ci`; отдельный owner-индекс не нужен — UNIQUE покрывает префикс owner_id).
- Интеграционные тесты (MySQL): persist+reload by id, UNIQUE-нарушение при двойном лайке, каскад при удалении item (`LikePersistenceTest`); findByOwnerAndItem, findById (null), findByItemId пагинация+детерминированный порядок, countByItemId, remove (`DoctrineLikeRepositoryTest`).

## Критерии приёмки

- [x] `LikeId` + `Like` entity + интерфейс (`save/remove/findById/findByOwnerAndItem/findByItemId/countByItemId`) + Doctrine-реализация.
- [x] UNIQUE `(owner_id, item_id)` в миграции; двойной лайк → UniqueConstraintViolation.
- [x] JOIN FETCH-цепочки в read-методах (нет ghost-proxy: Like→User, Like→Item→Collection→User).
- [x] Каскад: удаление айтема → лайки удалены.
- [x] Интеграционные тесты на реальном MySQL зелёные (8 тестов).
- [x] `ci:all` зелёный (467/1061); ревью-агенты (3: senior+architect+tech-lead); PR засквошен.
