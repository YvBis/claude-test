## Разбивка (решение по скоупу)

Один PR на четыре мажора — сценарий «бюджет контекста ×2» из CLAUDE.md 8,
поэтому декомпозиция заранее. `CLAUDE.md:51-54` не содержит клаузы об
исключениях из правила 2ч (зафиксировано senior-review мастер-плана
2026-09-29), поэтому PR-3 и PR-4 остаются атомарными по коммиту, но делятся
на проверяемые подзадачи ≤2ч каждая. Подзадачи — это **временные срезы одного
сквош-коммита**, а не отдельные коммиты: промежуточный срез вправе быть
красным, зелёный `ci:all` — критерий выхода PR, а не каждого среза
(красное никогда не попадает на main — сквош один). Пул срезов ниже —
обязательный минимум.

- **PR-1 (этот, 1ч)** — предусловия, без мажоров: миграция
  `TagServiceTest.php:81` `willReturnOnConsecutiveCalls` → `willReturnCallback`,
  жёсткий гейт депрекейшенов атрибутом `failOnDeprecation="true"`,
  переписывание `DeprecationConfigTest` под гейт, переписывание строки Roadmap
  5.25 под разбивку + новые строки (`lexik`, `nelmio`, решение по Messenger),
  правка `CLAUDE.md:370`.
- **PR-2 (1-1.5ч)** — rector 1.2.10 → 2.6 (+ дифф самого `rector.php`).
- **PR-3 (phpstan 1.12.33 → 2.2 + три расширения пачкой)** — два среза:
  - **PR-3a (≤1ч)** — бамп + проверка путей include в `phpstan.neon:2-4`
    и поведения `level 6`; прогон `composer phpstan`; **публикация списка
    новых находок без правок кода** (срез вправе закончиться красным —
    это список, а не результат).
  - **PR-3b (≤1.5ч)** — разбор находок, точечные правки, зелёный `ci:all`
    (критерий выхода PR).
- **PR-4 (phpunit 11.5.56 → 12.5)** — три среза:
  - **PR-4a (≤1ч)** — совместимость: `dama/doctrine-test-bundle` 8.6.0

    вместо внятного `coverage-gate: …` + `exit 1`). Срез идёт до бампа,
    поэтому закрывается зелёным `ci:all` на PHPUnit 11.

  - **PR-4c (≤1ч)** — разбор падений, зелёный `ci:all` (критерий выхода PR).

## Гипотезы (до реализации)

- **H1 (слой гейта):** `failOnDeprecation="true"` в `phpunit.xml.dist`
  покрывает любой вызов (CI `coverage:gate`, локальный `ci:all`,
  прямой `vendor/bin/phpunit`), а флаг `--fail-on-deprecation` в скрипте
  `phpunit` — только путь `coverage:gate`. Ответ лежит в `composer.json:97-98,110-111,116-119`:
  `ci:test` → `@phpunit:no-coverage` идёт мимо скрипта `phpunit`.
  `--display-deprecations` в скрипте остаётся ради вывода.
- **H2 (линия чистая):** полный прогон с `--display-deprecations` —
  `OK (764 tests, 2677 assertions)`, 0 депрекейшенов (замерено 2026-09-29).
  Значит гейт включается сразу, негативная проба обязана ронять прогон.
- **H3 (guard-тест):** `DeprecationConfigTest:60-64` (флаг в скрипте) заменяется
  на атрибут в конфиге; `:65-74` (grep + `GITHUB_STEP_SUMMARY`) не трогаем —
  на падении warning избыточен, но публикация в summary полезна, это не
  мёртвый код; `:166-175` (`disabled=1` остаётся) сохраняется, но формулировка
  «депрекейшены отключены намеренно» станет ложной (bridge на 11 — no-op,
  реальный гейт теперь нативный) — переписываем текст, переменную не трогаем
  (её удаление — отдельное решение). `continue-on-error` в шаге уже
  отсутствует (`:75-79` это пинят), advisory-форма жила только в grep'е.
- **H4 (ассерт):** `TagServiceTest.php:81` — последнее место
  `willReturnOnConsecutiveCalls` (поиск рекурсивный, не `-List` на маске:
  первый замер «ноль вхождений» был ложным из-за нерекурсивного поиска —
  зафиксировать как урок). `willReturnCallback` с замыканием по счётчику —
  та же семантика (beta, alpha), тест `testResolveByNamesPreservesFirstOccurrenceOrder`
  не меняется.
- **H5 (XSD-guard — НЕ здесь):** перенесён в PR-4 решением пользователя.
  Причины: на схеме 11 он ловит только устаревание, а не свой исходный баг
  (тихий скип DAMA — рантайм-поведение, уже прикрыт
  `StaticDriver::isKeepStaticConnections()`); шаг вида
  `vendor/bin/phpunit --migrate-configuration` столкнулся бы с
  `DeprecationConfigTest::INVOCATION_PATTERN` (`:48`) и уронил
  `testTheJobRunsTheSuiteExactlyOnce`; семантика «переписывает ли файл на
  месте» не измерена (на актуальном файле md5 не меняется, exit 0 —
  замерено 2026-09-29; на устаревшем — первый шаг PR-4 на temp-копии).
- **H6 (трекер):** строка Roadmap 5.25 связывает `lexik`/`nelmio`/Messenger в
  одну задачу — вынос без правки строки противоречит трекеру. `fwd-13`
  («merged into 5.25») остаётся видимым до мержа PR-1 с отметкой о частичном
  закрытии (ассертная часть — здесь, XSD-часть — в PR-4).

## Решения (с ценой)

- `lexik/jwt` 3.2 и `nelmio/api-doc` 5.12 — отдельными задачами после 5.25.
  `lexik` — code-compat, не продуктовое: конверт 401 принадлежит нашему
  `JwtAuthenticationFailureSubscriber`, 5.12 вычистил deprecated-ключ;
  замороженные 401-тесты работают оракулом. `nelmio` — перезаморозка спеки:
  `check-openapi-fresh.sh` сравнивает побайтово, бамп молча не проедет.
- `symfony/redis-messenger` — оставить заявленной возможностью, отдельной
  строкой Roadmap. Redis и `ext-redis` остаются ради `cache.app` в dev;
  ленивый транспорт без `dispatch()` стоит ноль.
- `SYMFONY_DEPRECATIONS_HELPER=disabled=1` (`phpunit.xml.dist:54`) не трогаем:
  переменная инертна (5.24), но её удаление — отдельное решение с удалением
  теста `testPhpunitConfigKeepsDeprecationsDisabledForTheMainRun`.
