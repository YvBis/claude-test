# PRD 5.26 — бамп symfony-lsp 0.21.0 → 0.23.0 с повторным parity-зондом

Статус: выполнено (2026-09-28; ожидает сквоша и мержа за пользователем).
Roadmap: `5.26`, `done`.

Бамп без промежуточной 0.22.0 — по решению пользователя («прыгаем сразу»).
Цена решения: прирост/убыль диагностик измеряется только суммарно между
0.21.0 и 0.23.0, пер-версионной атрибуции нет; причины ниже — гипотезы из
changelog, а не измеренный факт.

## Исходные факты (проверены до замера)

- Пин `0.21.0` — `ci.yml:81`. Выпущены `v0.22.0` (2026-09-25) и `v0.23.0`
  (2026-09-26). Ассет `symfony-lsp-v0.23.0-linux-x64.tar.gz` на месте —
  `asset_name()` скрипта продолжает работать без правок.
- Скрипт версионно-безопасен: кэш-ключ CI содержит версию, `SHA256SUMS.${VERSION}`
  пер-версионный, guard-регекс `SymfonyLspConfigTest` версионно-agnostic
  (`\d+\.\d+\.\d+`). Бамп = одна строка в `ci.yml` + дефолт в скрипте;
  остальное — измерение.
- Job `symfony-diagnostics` в CI идёт 17–24 с — зонд из 5 прогонов стоит минуты.

## Гипотезы из changelog (до замера)

- `0.22.0` «Check YAML configuration keys and values in **every environment
  block**» → вероятный **прирост** диагностик (гоняем `--environment=test`).
- `0.23.0` «Stop reporting unknown names in files another environment loads
  (…`config/packages/test/`)» → вероятная **убыль**.
- `0.23.0` «Stop completing route names on Twig `path`/`url`» → риск **регрессии**
  по P6 (неизвестный route в Twig `path()`).
- `0.23.0` «Publish an empty diagnostic list while a runtime index is
  incomplete» → риск ложно-зелёного гейта для 5.14; фиксирую находкой, здесь
  не решаю.
- `route.missing_parameters` / `service.not_found` в релизах не упоминаются →
  слепое пятно P1/P3, скорее всего, сохранится; ответ даёт целевой эксперимент.

## Дизайн зонда (транзиентно, дефекты в коммит не идут)

- 6 дефектов 5.17 для прямого сравнения (P5 — реальный deprecated-ключ из 5.12).
- P1′: `path('route')` без обязательного параметра на месте генерации
  (гипотеза 5.17: код относится к call-site, а не к определению маршрута).
- P3′: не-abstract сервис с `@missing` (гипотеза: abstract вырезает компилятор;
  P4 той же формы с параметром сработал).
- P3″: прямая ссылка на несуществующий класс в autowire-аргументе.
- Прогоны: 0.21.0 × {runtime, source-only} + 0.23.0 × {runtime, source-only}
  + повтор 0.23.0-runtime на холодном индексе (N=2), `--format=json
  --environment=test`.
- Сырой JSON в репозиторий не идёт; в PRD — извлечённая таблица
  (код, файл, версия, режим) + команды воспроизведения.
- Конец задачи — `git status` без следов пробы (урок 5.17).

## Результаты

Прогоны `--format=json --environment=test` в контейнере (JSON сохранены вне
репозитория, воспроизведение — командами ниже):

| Прогон | Результат |
|---|---|
| 0.21.0 runtime | 4 диагностики, `complete: true` |
| 0.21.0 source-only | 0, `complete: true` (повтор 5.17) |
| 0.23.0 runtime | **те же 4**, `complete: true` — дрейфа ноль |
| 0.23.0 source-only | 0, `complete: true` — решение 5.17 держится |
| 0.23.0 runtime, холодный индекс (`rm -rf var/symfony-lsp var/cache/test`, N=2) | те же 4 |

Найденные 4 (обе версии, идентично): `parameter.not_found`
(`config/services.yaml:75`, P4), `template.not_found` (P2),
`route.missing_parameters` (`templates/probe_526_missing_param.html.twig:1`,
P1′), `route.not_found` (P6). Молчат обе версии: P1, P3, P3′, P3″, P5.

`--list-codes` на обеих версиях — **31 код, множества побайтово равны**
(сверено диффом файлов, не хвостом терминала — `tail -40` один раз показал
ложное отсутствие `config.unknown_key`; в PRD 5.17 сказано «30» — там ошибка
на единицу). Дрейф, если бы был, шёл бы из поведения, а не из набора кодов.

Развязка P1/P3 (цель 5.26):
- **P1 — (б) артефакт фикстуры.** `route.missing_parameters` срабатывает на месте
  генерации (`path()` без обязательного параметра, P1′ — на обеих версиях),
  а не на определении маршрута (P1 молчит). Фикстура 5.17 смотрела не туда.
  Это закрывает вопрос 5.17 («почему зонд не увидел код»), но не вопрос дизайна
  checker'а — должно ли определение тоже флагиться — он вне скоупа 5.26.
- **P3 — (а) слепое пятно checker'а в YAML `@`-аргументах service-определений.**
  Гипотеза abstractness мертва (P3′ concrete молчит так же); гипотеза удаления
  мертва (все 4 yaml-фикстуры видны в скомпилированном test-контейнере через
  `debug:container`, checker читает те же метаданные — и молчит). На 0.23.0 —
  то же молчание. Граница: другие позиции (autowire-атрибуты, PHP type-hint)
  не тестировались — вне скоупа 5.26.
- **P5 — корректно отсутствует**: 5.12 удалила deprecated-ключ по-настоящему;
  в 5.17 он был реинжектирован пробой.
- **P6 — регрессии нет**: «stop completing route names on Twig `path`/`url`»
  затронуло только completion, диагностика `route.not_found` на месте.
- Новых env-блок диагностик (0.22.0) и сужений (0.23.0) на проекте нет.

Воспроизведение (в контейнере, дефекты — из раздела «Дизайн зонда» выше):
`SYMFONY_LSP_VERSION=<0.21.0|0.23.0> bash scripts/symfony-lsp-check.sh
--environment=test --format=json [--source-only]`.

## Решение

_По данным: бамп + обновление комментариев/сообщений, привязанных к 0.21.x._

Развилка без вопроса: если source-only на 0.23.0 что-то найдёт — решение 5.17
опровергнуто, возвращаем второй прогон, гард ждёт 2 вызова, фиксирую в PRD.
