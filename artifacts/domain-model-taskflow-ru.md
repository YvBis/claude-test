## 2. Связи

- Один пользователь может владеть многими коллекциями.
- Одна коллекция пренадлежит одному пользователю.
- Одна коллекция может иметь много айтемов.
- Один пользователь может иметь много айтемов.
- Один айтем может иметь одну коллекцию.
- Один айтем может принедлежать только одному пользователю.
- Одна коллекция может иметь много полей.
- Одно поле принадлежит одной коллекции.
- У полей принадлежащих коллекции все слот индексы уникальны.
- Один тег может принадлежать многим айтемам.
- Один айтем может иметь много тегов многим тегам.
- Один лайк принадлежит одному пользователю для одного айтема.
- Айтем может иметь много лайков от разных пользователей.
- Пользователь может иметь много лайков для разных айтемов.
- Пользователь может иметь много комментов.
- Айтем может иметь много комментов.

## 3. Базовые правила домена

- Коллекция должна иметь владельца.
- Айтем должен иметь владельца.
- После создания коллекции кастомные поля в ней не могут добавляться или удаляться, только меняться названия.
Агент может задавать вопросы в случае непонимания логики.

## 4. Темы коллекций

Для MVP используются темы:

- `Books`
- `Games`
- `Movies`
- `Drinks`

## 5. Неопределённости, оставленные на решение агента

Агент может принять решение по:

- способу получение имен полей от айтема;
- наличию soft delete;
- формату ограничений длины полей;
- деталям валидаций;
